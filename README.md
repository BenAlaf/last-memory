# Last Memory

**Last Memory** is a third-person 3D Unity game developed as a final project at Afeka College. The player controls a warrior who wakes up in a mysterious village with no memory, and must explore, battle enemies, and uncover the truth hidden in a northern castle.

## Game Features

- Third-person 3D character controller
- Dialogue system with NPCs and story progression
- Multiple environments: village, forest, castle
- Quest and task system with unlockable paths
- Background music, ambient sounds, and voice narration
- Enemy AI and final boss encounter
- Fully animated characters and UI menus

## Technologies Used

- Unity
- C# (MonoBehaviour scripting)
- Unity Animator and NavMesh
- Git & GitHub

## Repository Contents

This repository includes the project configuration (`Packages/`, `ProjectSettings/`) and core logic.  
Due to size limits, the `Assets/` folder is not included here.
